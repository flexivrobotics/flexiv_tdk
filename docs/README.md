# GitHub Pages Docs

This directory contains the documentation site source for GitHub Pages, built with MkDocs + Material theme.

## Local preview

```bash
pip install "mkdocs-material<9.7.2" "mkdocs-static-i18n==1.3.1"
mkdocs serve
```

The site will be available at http://127.0.0.1:8000/flexiv_tdk/.

## Multi-language (i18n)

The site supports 5 languages via the `mkdocs-static-i18n` plugin (suffix structure):

| Locale    | Language             | Example file suffix |
| --------- | -------------------- | ------------------- |
| `en`      | English (default)    | `index.md`          |
| `zh`      | 简体中文             | `index.zh.md`       |
| `zh-Hant` | 繁體中文             | `index.zh-Hant.md`  |
| `de`      | Deutsch              | `index.de.md`       |
| `ja`      | 日本語               | `index.ja.md`       |

- To translate a page, create a sibling file with the locale suffix. Pages without a translation fall back to English.
- Navigation titles for each language are translated via `nav_translations` in `mkdocs.yml`.
- Language-specific UI strings come from the Material theme; the locale code must match a theme language file (that's why Simplified Chinese uses `zh`, not `zh-Hans`).

### Linking to static files from translated pages

Static files (Doxygen output, `versions.json`, JS) are published **only under the default (English) language directory**. Therefore, in translated pages, relative links to static files must point one extra level up to the root language:

- from `index.zh.md` (site root level): `../api/doxygen/index.html`
- from `user-manual/quick-start-cpp.zh.md`: `../../api/doxygen/index.html`

Links between `.md` pages and image paths are rewritten by MkDocs automatically and need no adjustment.

## API reference (multi-version)

The C++ API is generated by Doxygen for **every release tag** that contains `docs/doxygen/Doxyfile.in`:

- `docs/doxygen/build_api_docs.sh` checks out each tag via `git worktree`, builds Doxygen into `docs/api/doxygen/<tag>/`, mirrors the latest tag to `docs/api/doxygen/` (for backward-compatible links), and writes `docs/api/versions.json`.
- The version dropdown on the [API index page](api/index.md) is populated from `versions.json` by `docs/api/version-switcher.js` — no manual updates are needed when a new release is tagged.
- The GitHub Actions workflow runs this script on every build (checkout uses `fetch-depth: 0` to fetch all tags).

To generate locally:

```bash
sudo apt install doxygen graphviz
bash docs/doxygen/build_api_docs.sh
mkdocs serve
```

Then open http://127.0.0.1:8000/flexiv_tdk/api/ and switch versions with the dropdown.

Generated outputs (`docs/api/doxygen/`, `docs/api/versions.json`) are git-ignored.
