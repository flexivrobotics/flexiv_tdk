# ユーザーマニュアル概要

!!! warning "重要"

    Flexiv TDK でロボットを使用する前に、ロボットに付属するすべてのドキュメントと本マニュアルを熟読し、これらに記載されたすべての安全指示を厳守してください。

本マニュアルでは、Flexiv TDK（遠隔操作開発キット）をインストール、設定、使用して、LAN または WAN 経由の遠隔操作アプリケーションを構築する方法を説明します。

## 対象読者

- 遠隔操作機能を統合するアプリケーション開発者
- Flexiv システムを導入するロボットエンジニア
- カスタムのロボット対ロボット遠隔操作ワークフローを構築する研究者

## 前提条件

### ロボット
- TDK v2.x では Enlight シリーズロボットが少なくとも 2 台必要です（TDK v1.x では FT センサー設定済みの Rizon シリーズロボット）

### ネットワーク機器
- 十分な帯域幅と低遅延を備えたネットワーク機器（イーサネットスイッチ/ルーターなど）
- CAT 6 または CAT 7 イーサネットケーブル

### ユーザー PC
- Ubuntu 22.04+（x86_64 または aarch64）
- C++ ツールチェーン：GCC ≥ 9.4、CMake ≥ 3.16.3
- Python 3.10/3.12/3.14
- ロボットおよびインターネットへのネットワークアクセス（WAN の場合）

## 始め方

- まず[システムセットアップ](./system-setup.md)を完了してください
- SDK が初めての方は、[クイックスタート (Python)](quick-start-python.md) または[クイックスタート (C++)](quick-start-cpp.md) から始めてください。
- ハードリアルタイム性能が必要ですか？[リアルタイムカーネル](real-time-kernel.md)を参照してください。
- WAN で展開しますか？[時刻同期 (WAN)](time-sync.md)を参照してください。
- API ドキュメントをお探しですか？[API ドキュメント](../api/index.md)を参照してください。
