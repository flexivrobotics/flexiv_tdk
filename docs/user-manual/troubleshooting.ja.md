# トラブルシューティング

## ビルドの問題

- **CMake が Flexiv TDK を見つけられない**：`-DCMAKE_PREFIX_PATH=~/tdk_install` がインストールプレフィックスを指していることを確認してください。
- **依存関係が不足している**：`thirdparty/build_and_install_dependencies.sh` を再実行し、インストールディレクトリが存在することを確認してください。

## 実行時の問題

- **共有ライブラリが見つからない**：バイナリを実行する前に `LD_LIBRARY_PATH=~/tdk_install/lib` を設定してください。
- **リアルタイム優先度の権限問題**：`/etc/security/limits.conf` にユーザーの `rtprio` と `nice` の設定を追加してください。

## WAN 遠隔操作

- **高遅延 / 動作が不安定**：ネットワークの安定性を確認し、時刻同期を再確認してください。
- **時刻同期が不正確**：`chronyc tracking` を使用し、`chronyc burst` と `chronyc makestep` の再実行を検討してください。

## リーダーロボットのドリフト

- リーダーロボットのツールの慣性パラメータキャリブレーションを確認し、設定されたツールが実際に現在使用しているものであることを確認してください。
- リーダーロボットの TCP 位置が、人の手が実際に握る位置に設定されていることを確認してください。
- TDK サンプルの起動時、センサーをキャリブレーションするかどうかは実際の入力パラメータによって決まります。初期化時にセンサーキャリブレーションを選択した場合、キャリブレーションにはしばらく時間がかかるため、その間はデバイスに触れないでください。
