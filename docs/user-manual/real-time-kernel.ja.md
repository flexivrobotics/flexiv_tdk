# リアルタイムカーネルオプション

すべてのユースケースでリアルタイム OS が必要なわけではありません。必要かどうかを判断するために以下をお読みください。

## ⚙️ リアルタイム性能のためのカーネルオプション

Ubuntu はワークロードに応じた複数のカーネルバリアントを提供しています：

| カーネルタイプ      | 説明                                                   | 典型的なユースケース                 |
| ------------------- | ------------------------------------------------------ | ------------------------------------ |
| `generic`           | デフォルトカーネル：性能と電力管理のバランス           | 一般的なデスクトップ/サーバー用途    |
| `lowlatency`        | 割り込み遅延を低減；スケジューリング応答性が向上       | ロボット、音声処理、ソフトリアルタイム |
| `rt`（`PREEMPT_RT`）| 完全プリエンプティブ；ハードリアルタイムの決定性       | 産業制御、ミッションクリティカルなシステム |

---

## ⚠️ 重要な免責事項

**低遅延**または**リアルタイム（RT）カーネル**へのアップグレードは以下を引き起こす可能性があります：
- プロプライエタリドライバ（NVIDIA、Wi-Fi モジュールなど）の破損
- システムの不安定化や起動失敗

カーネル変更に起因する問題については**ご自身で全責任を負う**ことになります。
✅ 作業前に**必ずシステムをバックアップ**してください。

---


## Ubuntu/x86-64 に低遅延または PREEMPT_RT カーネルをインストールする

### オプション 1：低遅延カーネル

1. **カーネルのインストール**：
   Hardware Enablement (HWE) スタックの場合（`uname -r` で確認；例：カーネル 6.x の Ubuntu 22.04）：

   ```bash
   sudo apt update && sudo apt install --install-recommends linux-lowlatency-hwe-22.04  # "22.04" をお使いのバージョンに置き換え
   ```
   オリジナルカーネル（5.15）の場合：
   ```bash
   sudo apt update && sudo apt install --install-recommends linux-lowlatency
   ```

2. **低遅延カーネルを優先するよう GRUB を設定**：
   ```bash
    echo 'GRUB_FLAVOUR_ORDER="lowlatency"' | sudo tee -a /etc/default/grub
    sudo update-grub
   ```

3. **再起動して確認**：
    ```bash
    sudo reboot
    uname -r  # "...-lowlatency" と表示されるはず
    ```

  🔄 ``generic`` に戻すには、``GRUB_FLAVOUR_ORDER`` を ``"generic"`` に変更し、``sudo update-grub`` を実行します。

### オプション 2：PREEMPT_RT カーネル

このページに記載されている Ubuntu リリースはリアルタイムカーネルをネイティブサポートしており、いくつかのコマンドで簡単に有効化できます。完全なチュートリアルは https://ubuntu.com/real-time を参照してください。


> ℹ️ Ubuntu 22.04/24.04 ユーザーは**無料の Ubuntu Pro サブスクリプション**で RT カーネルを有効化できます。個人利用は無料です。

> ℹ️ Nvidia Jetson（**aarch64**）の場合は、Nvidia の公式ドキュメントを参照してください。
