flexiv::tdk::AxisLock Struct Reference

Data for locking axis, including reference frame and axis to be locked for transparent cartesian teleop. Coordinate type options are: COORD_TCP ("TCP") for TCP frame and COORD_WORLD ("WORLD") for WORLD frame. More...
