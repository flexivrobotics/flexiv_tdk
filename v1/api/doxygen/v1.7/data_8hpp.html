◆ TeleopIssueCode

enum class flexiv::tdk::TeleopIssueCode
strong
Note
Host applications should switch on this code for localization. The English title/description/suggestion in TeleopIssue are defaults for logs and simple UIs.
Enumerator
NONE 

No issue.

JOINT_LIMIT 

A joint is near its position limit.

SINGULARITY 

Arm is near a kinematic singularity.

HIGH_JOINT_VELOCITY 

Joint velocity is close to the safety limit.

HIGH_LATENCY 

Network latency exceeded the configured threshold; teleop is force-disengaged.

NETWORK_DISCONNECTED 

Connection to the peer is not established.

CLOCK_MISMATCH 

Clocks disagree (negative latency); teleop is force-disengaged.

ROBOT_FAULT 

Robot is in fault state.

ROBOT_NOT_OPERATIONAL 

Robot is not operational (E-Stop, disabled, or link lost).

CONTROL_MODE_MISMATCH 

Robot left real-time Cartesian motion-force mode.

Examples
transparent_cartesian_teleop_wan.cpp, and transparent_cartesian_teleop_wan_pro.cpp.
