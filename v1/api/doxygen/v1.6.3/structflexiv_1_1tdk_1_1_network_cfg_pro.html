std::vector<std::string> flexiv::tdk::NetworkCfgPro::lan_interface_whitelist = {}
Parameters
lan_interface_whitelistLimit the network interface(s) that can be used to try to establish connection with the robot via ethernet cable. The whitelisted network interface is defined by its associated IPv4 address. For example, {"10.42.0.1", "192.168.2.102"}. If left empty, all available network interfaces will be tried when searching for connection.
