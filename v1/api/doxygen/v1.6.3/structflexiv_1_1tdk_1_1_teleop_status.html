Detailed Description

[primary] is the issue the host should show first: the highest-level active issue, or the last significant event if nothing is active. [issues] lists every condition that is active right now.

◆ latency_ms

double flexiv::tdk::TeleopStatus::latency_ms = 0.0

Estimated one-way message latency in milliseconds. WAN only; 0 on LAN. Negative means clock mismatch. A very large value means not connected.
